# KebianOS_Welcome

Kebianos Welcome es una applicacion de bienvenida para la distribucion KebianOS

## Compilar
Para compilar el proyecto, solo haga `make` y para compilarlo y probarlo sin instalarlo haga `make run`

## Instalacion

Si desea instalar el programa debera de escribir `make install` en la rais de la carpeta, esto instalara la dependencia nesesaria para que pueda compilarlo e instalara la applicacion en su sistema e instalara la aplicacion en su sistema.
